# DetectKB user manual

The user manual (in Persian) with screenshots of every section:

- [`DetectKB-User-Manual.pdf`](DetectKB-User-Manual.pdf): for reading and printing
- [`DetectKB-User-Manual.docx`](DetectKB-User-Manual.docx): editable Word version

## Rebuilding

The manual is generated by `build.js` (the [docx](https://www.npmjs.com/package/docx) package) from the text in the script and the images in `img/`.

```bash
cd docs/user-manual
npm install
npm run build          # writes DetectKB-User-Manual.docx
soffice --headless --convert-to pdf DetectKB-User-Manual.docx   # optional, needs LibreOffice Writer
```

The Word file uses Tahoma for Persian text, so it looks right on Windows. On Linux, map Tahoma to a Persian font (e.g. Vazirmatn) before converting to PDF.

## Updating the screenshots

`scripts/capture.cjs` takes the raw screenshots with Playwright from a running instance with data loaded. It writes them to `shots/`, which git ignores:

```bash
KB_URL=http://localhost:5173 KB_USER=admin KB_PASSWORD=... npm run screenshots
```

The images in `img/` are cropped JPEG versions of these, named the same, with their pixel sizes listed in `img/sizes.json`. Crop a new screenshot the same way, then update `sizes.json` and rebuild.
